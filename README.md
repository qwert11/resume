# Одностраничное резюме

Живая страница: **https://qwert11.github.io/resume/** — полная версия лежит в
[resume2](https://github.com/qwert11/resume2) и открывается по ссылке из футера.

## Откуда берутся данные

Здесь нет своей копии фактов. `scripts/fetch_source.py` при каждой сборке тянет
YAML из `qwert11/resume2/data` — имя, контакты, опыт, стек, образование.
Скачанное кладётся в `data/` и коммитится как снимок: так сборка переживает
отсутствие сети, а `git diff` показывает, что изменилось в источнике.

Правки фактов вносятся в resume2. Эта страница пересобирается: при пуше в свои
файлы, по расписанию раз в сутки и вручную через `workflow_dispatch`.

## Что попадает на страницу

Одностраничник — это вехи, собранные из подробного резюме, а не его сжатая
копия. Отбор описан в `onepager.yaml`:

| Ключ | Смысл |
| --- | --- |
| `jobs` | какие позиции показать и какие пункты (по номеру в `experience.yaml`) считать вехами; остальные позиции сворачиваются в строку «Раніше» |
| `skills` | группы стека в боковой колонке. Только актуальная версия каждой технологии: `.NET 7`, а не `.NET 7 / 6 / 5`; история версий остаётся в полном резюме |
| `metrics`, `max_metrics` | какие цифры вывести под кратким описанием |
| `max_education` | сколько записей об образовании показать |

## Сборка

```bash
pip install -r requirements.txt
python scripts/build.py              # с обновлением данных из resume2
python scripts/build.py --skip-fetch # из локального снимка
```

Результат — `output/site`: `index.html`, а также `resume.pdf` / `.docx` / `.md`
на английском и `resume.uk.*` на украинском. Кнопки скачивания переключаются
вместе с языком интерфейса. PDF собирается reportlab-ом в той же двухколоночной
раскладке и тоже помещается на одну страницу; сборка предупреждает, если колонка
не влезла.

## Вёрстка

- **Лист.** Тёмная боковая колонка (контакты, навыки, языки, образование) и
  основная (имя, описание, цифры, опыт). На экране лист имеет пропорции A4.
- **Печать.** `Ctrl+P` даёт ровно одну страницу A4 без полей: боковая колонка
  идёт на всю высоту, элементы управления скрыты, кегли переведены в пункты.
  Проверено headless Chrome на обоих языках.
- **Телефон.** Одна колонка от 320 px: сначала основная часть, ниже боковая.
- **Темы.** «Авто» — светлая с 07:00 до 19:59 по локальному времени, иначе тёмная.
- **Языки.** «Авто» — украинский для киевской таймзоны или `uk`-локали, иначе
  английский. Параметр `?lang=uk|en` в адресе принудительно задаёт язык.
